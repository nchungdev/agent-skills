# 🎬 Media Collector Plugin (`media-collector`)

Universal film, anime, and TV show curator plugin for **Antigravity**.

## 🌟 Capabilities
1. **Franchise Census & ID Mapping**: Cross-references TheTVDB (`{tvdb-XXXXX}`) and TMDb (`{tmdb-XXXXX}`) metadata.
2. **Plex & Jellyfin Architecture**: Zero-guesswork directory layout for TV Shows, Movies, OVAs, Behind The Scenes, and Trailers.
3. **Multi-Source Subtitle Scraper**: Integrated hunting across SubDL, OpenSubtitles, ACG.RIP, ASSRT, and Anime Tosho.
4. **Subtitle Engineering**: SRT to 1080p styled ASS conversion, timecode offsets, and multi-language standard naming.
5. **Verified Download Blueprints**: Automated `DOWNLOAD_LINKS.txt` compilation for 1080p/4K BDRip & WEB-DL releases.
