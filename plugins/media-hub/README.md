# 🚀 Antigravity Media Hub & AI Agent Command Center Plugin

Plugin trung tâm điều khiển và giám sát toàn diện hệ thống **Antigravity Media Hub**, tích hợp trực quan giữa đám mây **TorBox Debrid**, kho lưu trữ **Google Drive** và trợ lý thông minh **AI Agent Assistant**.

---

## 📦 Các Kỹ Năng (Skills) Trong Plugin

* **`media-hub`:** Khởi chạy máy chủ Dashboard HTTP thời gian thực (cổng `8888`), cung cấp giao diện Web trực quan và các API REST để giám sát tác vụ, quản lý TorBox, duyệt kho Google Drive và gửi lệnh tương tác cho AI Agent.

---

## 🛠️ Cài Đặt & Sử Dụng

### Khởi chạy Dashboard:
```bash
python3 plugins/media-hub/skills/media-hub/scripts/server.py
```

Truy cập: **`http://127.0.0.1:8888`**
